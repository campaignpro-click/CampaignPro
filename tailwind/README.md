# Site styles

The site uses a pre-built stylesheet, `assets/styles.css`, generated by Tailwind CSS from the classes used in the `.html` files. The page no longer loads Tailwind from its CDN, which makes it load faster.

If you add or change Tailwind classes in an HTML file, rebuild the stylesheet, otherwise the new classes will have no effect:

```
npx tailwindcss@3 -c tailwind/tailwind.config.js -i tailwind/input.css -o assets/styles.css --minify
```

Then bump the `?v=` number on the `styles.css` link in each HTML file so browsers load the new version.

Brand colors and shared component styles (buttons, cards, FAQ) live in `tailwind.config.js` and `input.css`.
